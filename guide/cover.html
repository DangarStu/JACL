Build text adventures that play in a terminal, a browser, or anywhere in between.

JACL is a small, interpreted programming language for writing interactive fiction. Its standard library does the heavy lifting — the parser, the world model, 216 ready-built verbs — so the author can focus on the writing.

This is the authoritative reference, taking you from your first room to a finished game ready to publish online.

Inside

  • A complete tutorial game, walked through step by step
  • The full object, location, attribute and grammar reference
  • The web interface library for browser play — with auto-save, voice synthesis and a clickable command bar
  • Multimedia, menus, CSV-backed data and timed events
  • Three appendices: every attribute, every library verb, and the source code for the tutorial game
