The JACL Author's Guide

Seventh Edition

JACL is a programming language for writing interactive fiction — the kind of text adventure where the player types commands and reads what happens next.

This book is the reference for authors. It walks through writing a complete game from scratch, then takes a chapter-by-chapter tour of every language feature: objects, locations, attributes, grammar, flow control, the standard library of verbs, the menu system, the web interface, multimedia, and the JACL-to-HTML pipeline used by the cgijacl and fcgijacl interpreters.

Three appendices give the complete attribute table, the full set of 216 library verbs, and the source code for the tutorial game.
